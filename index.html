还差最后一步

打开项目里的 config.js，把 Supabase 的 Project URL 和 anon public key 填进去即可。

  1. supabase.com 注册免费账号 → New Project
  2. SQL Editor 里运行 supabase-setup.sql（见项目说明文档）
  3. Authentication → Sign In / Providers：关闭邮箱与手机号「确认」
  4. Project Settings → API：复制两个 key 填入 config.js
  5. 重新部署
